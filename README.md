# Prism Insurance Analysis Dashboard | Power BI

## Project Overview

This project presents an interactive Insurance Analysis Dashboard developed using Microsoft Power BI. It provides an overview of insurance policies, premiums, coverage amounts, claims, and customer demographics.

The dashboard helps users explore insurance performance, understand claim status distribution, and analyze policy-related metrics through interactive filters and visualizations.

## Dashboard Pages

### 1. Insurance Overview
The overview page provides a high-level summary of insurance performance through KPI cards and interactive visuals.

**Key KPIs:**
- Total Premium Amount
- Total Coverage Amount
- Total Claim Amount
- Active and Inactive Policy Count
- Gender Distribution

**Visualizations:**
- Premium Amount by Policy Type
- Number of Claims by Claim Status
- Claim Amount by Age Group
- Active vs. Inactive Policies
- Policy Type and Claim Status Summary

**Interactive Filters:**
- Policy Number
- Claim Number
- Customer ID

### 2. Policy Details
The detailed page provides policy-level information in a tabular format, including:
- Policy Number
- Customer ID
- Claim Number
- Age and Gender
- Coverage and Premium Amount
- Policy Start and End Dates
- Policy Type
- Claim Status and Claim Date
- Claim Amount
- Age Group
- Active/Inactive Policy Status

The report also includes drill-through functionality to support more detailed analysis.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Objectives
- Monitor insurance premium, coverage, and claim amounts.
- Analyze claims across different statuses.
- Compare premium amounts across policy types.
- Understand customer distribution by gender and age group.
- Monitor active and inactive insurance policies.
- Explore individual policy and claim details.
